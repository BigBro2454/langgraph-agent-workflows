Simple LangGraph Agent Documentation

Overview

This document details the architecture and implementation of a minimal AI agent built using LangGraph and LangChain, and powered by Google's gemini-3.1-flash-lite model.

Architecture Flowchart

The agent operates on a directed state graph. The state maintains a continuous conversation history, which is processed by the chatbot node on each turn.

State Definition

The application state is defined as a TypedDict containing a list of messages. The add_messages reducer is crucial here; it ensures that new messages from the user and the LLM are appended to the history rather than overwriting it.

from typing import Annotated
from typing_extensions import TypedDict
from langgraph.graph.message import add_messages

class State(TypedDict):
    messages: Annotated[list, add_messages]

Node Logic

The graph consists of a single operational node: the chatbot. When executed, this function takes the current state (message history), passes it to the Gemini model, and returns a dictionary with the newly generated response. LangGraph then uses the reducer to update the global state.

Execution Flow

  1. Initialization: The user provides a text prompt, which is formatted as a message and injected into the initial state.
  2. Routing: The graph begins execution at the START node and transitions directly to the chatbot node.
  3. Processing: The chatbot node queries the LLM and yields the response.
  4. Termination: The flow moves automatically to the END node, returning control to the terminal loop to await the next user input.
